# MyWaveQt：语音信号分析与端点检测系统

MyWaveQt 是一个面向**科研训练**的桌面语音信号分析项目。项目使用 C++23 和 Qt 6 开发，以语音活动检测（Voice Activity Detection，VAD）为核心，同时提供语音波形显示、时频域特征分析、基音检测、MFCC 提取以及基于 GMM 的说话人识别功能。

本项目并非通用音频编辑器或完整语音识别系统。它的主要目标是将语音信号处理中的关键步骤可视化，使算法的输入、参数、中间特征和输出结果能够被观察、比较与验证，适合用于科研训练、课程实验和算法原型研究。

## 项目背景

语音信号通常具有明显的短时平稳特性，因此多数分析方法会先对信号进行预加重、分帧和加窗，再提取短时能量、过零率、频谱、倒谱、Mel 频谱等特征。本项目围绕这一处理链路，实现了从音频读取到特征显示、端点检测和说话人建模的完整实验流程。

项目参考并迁移了仓库中 `资料3_语音波形读取及显示范例程序` 下的 MyWave VS2010/MFC 示例。Qt 版本保留其主要算法与实验目的，同时修复了旧工程中的平台依赖、硬编码路径、内存管理及部分数值实现问题。

## 主要功能

### 音频与可视化

- 读取 WAV、FLAC、OGG、MP3 等 libsndfile 支持的格式；
- 显示单声道混音、左声道和右声道波形；
- 支持通过文件多选或拖放一次加载多个音频，并在文件选择器中切换当前分析对象；
- 支持将当前音频的选区另存为 WAV；
- 支持图表平移、缩放、曲线显隐和颜色调整；
- X、Y 轴缩放统一使用放大倍数表示，`1.00x` 代表完整/原始尺度；
- 多种量纲的曲线使用独立归一化分层显示，并共享样本索引轴；
- 整帧边界使用蓝色实线、半帧边界使用橙色虚线标识；
- 图表区与操作区通过可拖动分隔条调整高度，操作面板采用横向自适应分组；
- 图表背景、坐标轴、图例、提示框及帧网格支持 Qt 明暗主题动态切换；
- 可将图表导出为 PNG 或 PDF。

### 时域分析

- 线性短时能量（PCM16 幅值平方和，不进行对数或 dB 转换）；
- 短时平均振幅；
- 线性短时过零率；
- 修正自相关函数；
- ACF、AMDF 和倒谱法基音检测。

短时能量和过零率均按 50% 重叠帧计算。每个特征值绘制在对应帧的中心位置，并以普通折线连接，便于观察随时间变化的趋势。对数功率谱、倒谱、MFCC 和部分 VAD 门限中的对数运算属于各自算法定义，不受此显示约定影响。

### 频域与倒谱分析

- 幅度谱与功率谱；
- 对数功率谱；
- 频谱的频谱（二次 FFT）；
- 真实倒谱；
- Mel 频谱；
- 13 维 MFCC；
- LPC、LPCC 与 LPC 合成语音；
- 基于 STFT 的二维语谱图。

### 端点检测

项目提供多种 VAD 方法，其中 `reference` 是与 MyWave 示例项目对应的主要算法：

1. 计算每帧短时能量和过零率；
2. 根据最高能量建立高、低两级能量门限；
3. 使用高门限确定候选语音段；
4. 删除持续时间过短的候选段；
5. 使用低能量门限向前、向后扩展边界；
6. 使用过零率门限进一步修正边界；
7. 合并重叠或相邻的语音段。

除此之外，还保留了能量 VAD、过零率 VAD 和实验性的倒谱 VAD。界面中可以修改门限、最小语音帧数等参数，并将有效语音帧的 MFCC 导出为 TSV 数据。

### 说话人识别

- 从一个或多个训练音频中提取 13 维 MFCC；
- 支持 2、4、8、16、32、64 阶对角协方差 GMM；
- 使用平均对数似然进行说话人辨认；
- 使用可调阈值进行说话人身份确认；
- 模型以 JSON 形式保存在系统应用数据目录中。

说话人确认阈值与录音设备、环境、语料和训练时长有关，开展实验时应在独立验证集上重新标定，不能直接将界面默认值视为通用阈值。

## 技术栈

| 组件 | 用途 |
|---|---|
| C++23 | 核心业务与信号处理 |
| Qt 6 | GUI、音频播放、并发和跨平台支持 |
| QCustomPlot 2.1.1 | 波形、特征曲线和语谱图绘制 |
| FFTW3 | FFT 与倒谱计算 |
| libsndfile | 音频解码与 WAV 写入 |
| CMake + Ninja | 构建系统 |
| vcpkg | FFTW3 与 libsndfile 依赖管理 |

Qt 由系统包管理器提供，以避免通过 vcpkg 编译完整 Qt 所产生的较长构建时间。

图表数据始终以完整分辨率保存在业务缓存中。只有在数据交给界面之前，才会根据当前可见区间统一执行一次 min/max 降采样；QCustomPlot 的自适应采样随后仅负责绘制阶段优化。这样可以兼顾长音频的显示性能，并在缩放后从完整数据重新取样，避免重复降采样造成的细节丢失。

## 构建环境

需要准备：

- CMake 3.20 或更高版本；
- Ninja；
- 支持 C++23 的 GCC、Clang 或 MSVC；
- Qt 6：Core、Gui、Widgets、PrintSupport、Multimedia、Concurrent、OpenGLWidgets；
- Qt Wayland 平台插件（Linux Wayland 环境）；
- vcpkg。

以 Arch Linux 为例，可先安装系统依赖：

```bash
sudo pacman -S --needed cmake ninja gcc qt6-base qt6-multimedia qt6-wayland
```

准备 vcpkg：

```bash
git clone https://github.com/microsoft/vcpkg.git "$HOME/.local/share/vcpkg"
"$HOME/.local/share/vcpkg/bootstrap-vcpkg.sh" -disableMetrics
export VCPKG_ROOT="$HOME/.local/share/vcpkg"
```

建议将 `VCPKG_ROOT` 写入自己的 shell 配置文件。若 vcpkg 仓库更新后出现工具数据 schema 不兼容，可重新执行一次 `bootstrap-vcpkg.sh` 更新 vcpkg 可执行文件。

## 编译与运行

Release 构建：

```bash
cmake --preset release
cmake --build --preset release
./build/MyWaveQt
```

Debug 构建：

```bash
cmake --preset default
cmake --build --preset default
./build/MyWaveQt
```

首次配置时，vcpkg 会自动安装 FFTW3、libsndfile 及其依赖。生成目录为 `build/`。

## 基本使用流程

1. 通过工具栏、文件菜单或拖放方式加载音频；
2. 设置全局帧长，默认值为 512；操作面板支持在 64～4096 的二次幂之间选择，菜单提供常用帧长快捷项；
3. 从“时域分析”“频域分析”“端点检测”菜单中启用需要的曲线；
4. 使用鼠标拖动画布、滚轮或操作面板调整观察范围；X、Y 缩放均以 `x` 倍率显示。未选择曲线时，Y 控件调整整个图表；选择具体曲线后，Y 控件仅调整该曲线；
5. 按住 `Shift` 并使用鼠标左键拖动以选择语音区间；
6. 在操作面板中播放选区，或通过文件菜单将选区保存为 WAV；
7. 导出图表或有效语音帧 MFCC，用于后续实验分析。

说话人识别实验流程：

1. 打开“说话人 → 说话人识别 / 确认”；
2. 输入说话人姓名并选择一个或多个训练音频；
3. 选择 GMM 阶数并训练模型；
4. 选择测试音频进行闭集辨认；
5. 选中一个说话人模型，设置阈值后进行身份确认。

## 测试与复现

运行自动化测试：

```bash
ctest --test-dir build --output-on-failure
```

`MyWaveDspTests` 构造一段 16 kHz、包含静音和 200 Hz 有声区间的合成信号，用于验证：

- 短时能量保持线性尺度，振幅扩大 2 倍时能量扩大 4 倍；
- 短时能量和过零率的横坐标位于各帧中心；
- 频谱、真实倒谱、Mel 频谱与 MFCC 能够正常生成；
- STFT 语谱图维度正确；
- 双门限 VAD 能检测出有声区间；
- ACF 基音算法能识别约 200 Hz 的基频。

进行科研实验时，建议同时记录以下信息：数据集及划分方式、采样率、帧长、帧移、VAD 门限、GMM 阶数、随机初始化方式和评价指标。端点检测可使用准确率、召回率、F1 或边界误差；说话人任务可使用识别准确率、FAR、FRR 和 EER。

## 当前边界

- 当前以离线音频分析为主，尚未实现麦克风实时采集；
- 说话人辨认属于闭集实验，不包含未知说话人拒识的完整开放集协议；
- GMM 模型适合教学和基线实验，不代表现代深度说话人表征方法；
- 不同音频格式可能由系统 libsndfile 的编译特性决定；
- 仓库中的旧 MFC 工程用于算法溯源和结果对照，不参与 Qt 版本构建。
